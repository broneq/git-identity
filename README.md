# git-identity - moved

This repository is archived. `git-identity` now lives in the BDK repository, with its full history:

**https://github.com/broneq/bdk/tree/main/plugins/git-identity**

- Install it from the BDK marketplace, as before: `/plugin marketplace add broneq/bdk`, then `/plugin install git-identity@bdk`.
- Issues and pull requests go to [broneq/bdk](https://github.com/broneq/bdk).
- Releases continue there as tags `git-identity--v<version>`. The tags of this repository stay readable, so existing pins keep working.
